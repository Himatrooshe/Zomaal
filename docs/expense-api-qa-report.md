## Environment and authentication

Production API URL:

```text
https://zomaal-backend-563898960389.us-central1.run.app/
```

The API calls below use the production Cloud Run URL. The isolated verification run used `http://127.0.0.1:3002` against a disposable local database.

All expense requests require:

```http
Authorization: Bearer <accessToken>
```

JSON requests also require:

```http
Content-Type: application/json
```

The access token comes from:

```http
POST https://zomaal-backend-563898960389.us-central1.run.app/auth/login
Content-Type: application/json

{
  "phone": "<configured logger/merchant phone in E.164 format>",
  "password": "<password>"
}
```

The account must have an active store. Store owners have all expense permissions. Staff need the applicable permission for each operation: `expenses.view`, `expenses.add`, `expenses.edit`, or `expenses.delete`.

### 4. Upload a receipt

The multipart field name must be `receipt`. Supported content types are real JPEG, PNG, or WebP bytes, maximum 5 MiB.

```http
POST https://zomaal-backend-563898960389.us-central1.run.app/expenses/receipts
Authorization: Bearer <accessToken>
Content-Type: multipart/form-data; boundary=<generated by client>

receipt=<binary image file>
```

Expected success response — `201 Created` when private image storage is configured:

```json
{
  "id": "<asset uuid>",
  "contentType": "image/png",
  "sizeBytes": 182430,
  "previewPath": "/expenses/receipts/<asset uuid>",
  "expiresAt": "2026-09-30T08:10:00.000Z"
}
```

Actual local response — `503 Service Unavailable` because cloud storage was not configured:

```json
{
  "message": "Unable to store product image",
  "error": "Service Unavailable",
  "statusCode": 503
}
```

QA note: the message says “product image” even though this is a receipt endpoint.

## Issues for QA/development follow-up

1. `POST /expenses/categories` and `POST /expenses` return `201 Created`, but their Swagger controller decorators advertise `200 OK`.
2. Receipt success flows require a configured `PRODUCT_IMAGE_BUCKET` and valid Google Cloud credentials. They were not available locally.
3. Receipt upload storage failures say `Unable to store product image`; a receipt-specific message would be clearer.
4. Summary/trend currently total rows in the Expense ledger. Automatic advertising, purchase, and shipping provider costs are not yet ingested into that ledger; this is a known module limitation.
